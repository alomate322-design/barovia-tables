# Кости Баровии — расширение для Owlbear Rodeo

Второе, отдельное расширение (не связано с Ravenloft Music). Это точная копия
твоего Artifact «Кости Баровии» — все случайные таблицы книги, маршрутный
калькулятор с автобросками столкновений, трекер боя (инициатива/хиты),
шкала «Страд следит», погода/луна и бестиарий с кликабельными чарниками —
упакованная как popover-расширение Owlbear Rodeo, вместо отдельной вкладки
браузера.

## Важно: это НЕ синхронизируется между игроками

В отличие от Ravenloft Music, у этого инструмента **нет** обмена состоянием
через комнату Owlbear Rodeo — он и в оригинальном Artifact работал точно
так же: все брошенные результаты, трекер боя, счётчик дня похода и т.д.
хранятся только в памяти вкладки/попапа того, кто его открыл, и исчезают
при закрытии. Это осознанное 1:1 повторение оригинала — справочник ведущего,
которым пользуешься только ты. Если в будущем захочешь, например,
синхронизировать трекер боя между твоим и запасным устройством — это можно
добавить отдельно (тем же способом, что и Ravenloft Music, через
`OBR.room.setMetadata`), просто скажи.

## Файлы

- `manifest.json` — манифест расширения.
- `icon.svg` — иконка (кубик к20).
- `index.html` — вся страница целиком (разметка + стили + скрипт), без
  внешних зависимостей, кроме шрифтов Google Fonts.

## Деплой на Render (шаги те же, что и для Ravenloft Music)

1. Зайди на github.com, создай **новый** репозиторий (можно приватный),
   например `barovia-tables`.
2. Залей туда все три файла из этой папки (`manifest.json`, `icon.svg`,
   `index.html`) — через «Add file → Upload files» или `git push`.
3. На render.com → **New → Static Site** → выбери этот репозиторий.
   - Build Command — оставь пустым.
   - Publish Directory — `.` (точка, корень репозитория).
4. После деплоя Render даст адрес вида `https://barovia-tables.onrender.com`.
5. Проверь в браузере, что манифест открывается:
   `https://barovia-tables.onrender.com/manifest.json` — должен вернуть JSON,
   а не ошибку.
6. Если после этого при установке в Owlbear Rodeo будет ошибка
   «Failed to fetch» — зайди в Render → твой сайт → **Settings → Headers**
   → добавь правило: Path `/*`, Name `Access-Control-Allow-Origin`,
   Value `*`. Это тот же самый CORS-фикс, что понадобился Ravenloft Music.

## Установка в Owlbear Rodeo

1. Extensions → Install extension → вставь ссылку на `manifest.json` из
   шага 5 выше.
2. Появится вторая кнопка — «Кости Баровии», рядом с Ravenloft Music.
3. Открывается popover пошире (под макет оригинальной страницы) — внутри
   него всё работает как в артефакте: разделы по якорям сверху, кнопки
   «Бросить»/«Рассчитать», клики по именам монстров открывают модалку с
   полным чарником.

Если что-то не отобразится или будет ошибка — как обычно, скриншот/консоль
(F12) сюда, разберусь.
